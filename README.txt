THUNDER OFFICE 3D - team.wondermayank.in

You start OUTSIDE: a garden, a water causeway and a palace-style building. Walk to the main door (knock and wait sign), go in, and explore.
  Ground floor : waiting area (rules poster), rest room, sleep room, stairs + lift
  Floor 2      : wide corridor, CA room at the end, two closed "Private" doors
  Floor 3      : 12 team rooms (6 left, 6 right) + Wondermayank's room at the end
  Floor 4      : common rooms (singing, dancing, living)
  Floor 5      : creativity, designer and tech rooms
  Terrace      : swimming pool, pergola swing, sofas, string lights
Each member room: bedroom -> door on left wall -> dress-storage corridor -> big bathroom (tub, shower, mirror, changing room).

Travel: stairs (west and east alternate) or the lift (panel with G/2/3/4/5/Roof). Floor buttons always land you on the floor.
Controls: desktop = drag to look, WASD/arrows, Shift run, click a picture or press E, M map.
          mobile = left joystick, drag right side to look, tap picture, tap floor to walk there.
Compass button = guided tour. Tap a member to see their card (nickname + skills).

Deploy: upload index.html, app.js, assets/, models/ to Cloudflare Pages (no build needed).
Edit:   src/data.js (rooms, floors, members, rules), then  npm install && npm run build  (writes app.js).
Bathroom pictures: add id to BATH_IMAGES in src/data.js and put assets/bath-<id>.webp (currently wondermayank, anamika).
Building / terrace pictures: assets/building.webp, assets/terrace.webp (EXTRA_PICS).
3D assets: see prompt.txt. Optional models/manifest.json "areas" list places .glb decor. Without .glb files, simple clay props are used.
Privacy: no address, locks, cameras or college details are shown; portraits and rooms are illustrations.
