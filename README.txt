THUNDER OFFICE 3D - team.wondermayank.in (prototype)
Walk through the office: start in the living room, hub with four corridors.
Controls: desktop = click to look, WASD/arrows to walk, Shift to run, E or click on a picture for details, M for map.
          mobile = left joystick to walk, drag right side to look, tap a picture.

Deploy: upload this folder (index.html, app.js, assets/, models/) to Cloudflare Pages. No build needed.
Edit:   change rooms/layout in src/data.js, then  npm install && npm run build  (writes app.js).
3D assets: see prompt.txt. Without .glb files the rooms use simple placeholder furniture.
Privacy: no address, locks or cameras are shown; portraits and rooms are illustrations.
